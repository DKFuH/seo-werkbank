# Editorial content-quality and CRO analysis

The checks use actual crawler metadata and explicitly user-entered evidence.
They are not a Google ranking signal or a measured conversion effect.

Four workflows:
1. Content evidence: record a claim and optional source link; a source URL is
   **not automatically verified**. Missing sources are highlighted.
2. CRO/landing pages: compare H1, metadata and lexical CTA hints from the latest
   crawl. Visual above-the-fold layout, mobile usability, actual form success and
   conversion rate need manual UX testing and opt-in analytics.
3. Comparisons: record product/item A and B, specific evaluation criteria and
   original source URLs. Unsourced comparisons are flagged; prices and other
   assertions are never invented.
4. Linkable assets: capture a genuinely useful tool/research/interactive asset
   brief and review accessibility, source quality, tracking consent and
   licensing before public distribution. The feature **does not generate or
   host working interactive applications**.

The new `/research-quality` dashboard reads records made in `/research`.
All requests enforce site ownership. No external publishing or link placement.
