# SERP-basiertes Keyword-Clustering

**Wo:** Sichtbarkeit → Keyword-Recherche → Cluster-Werkzeug → SERP-Overlap-Clustering.

1. Zwei bis fünfzehn Keywords eingeben (eine Zeile je Keyword).
2. Entweder einen SERP-Anbieter unter den Einstellungen aktivieren **oder** für jedes Keyword eine Ergebnisliste angeben: `Keyword | https://url1,https://url2` (eine Zeile pro Keyword).
3. Mindestanzahl gemeinsamer URLs auswählen (2–6 in der Oberfläche).
4. **SERP-Cluster berechnen**. Angezeigt werden Cluster über die Überschneidung der ersten zehn erhaltenen URLs je Keyword.
5. Zusammengefasste Gruppen redaktionell auf Suchintention, Zielland, SERP-Quelle und Überschneidung prüfen.

**Wichtig:** Der Algorithmus gruppiert transitive Überschneidungen; deshalb müssen nicht alle Keyword-Paare innerhalb eines Clusters die gewählte Schwelle erreichen. Er legt weder die optimale Seitengröße noch eine Rankinggarantie fest. Für echte Google-Rankings einen dafür geeigneten Datenanbieter verwenden. Das bestehende lexikalische Cluster-Werkzeug bleibt separat erhalten.

# Bedienhilfe und Screenshots

Unter **System → Hilfe** findest du die Anleitungen und Links zu jedem Werkzeug.
Echte Screenshots und ein WebM-Rundgang lassen sich mit `scripts/capture_demo.py` aus einer laufenden Installation erzeugen. Ohne eine echte gestartete Installation sind **keine Produktbilder behauptet oder vorgetäuscht**. Die Bilder werden zunächst lokal erzeugt und müssen vor der Veröffentlichung auf persönliche Daten geprüft werden.
